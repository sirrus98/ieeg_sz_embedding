================================================================================
TROUBLESHOOTING
================================================================================

Q: Import errors?
A: Scripts add code/ to sys.path automatically. Make sure code/utils.py exists.

Q: Permission denied?
A: Update OUTPUT_DATA_DIR in config_benchmark.py to a writable directory.

Q: No windows extracted?
A: Check that RAW_DATA_DIR points to correct BIDS directory with EDF files.

Q: Data not normalized?
A: Run test_extraction.py to verify. Should show mean≈0, std≈1.
